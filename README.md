# Slider Project

Учебный проект, выполненный в рамках курса SkillFactory.

## Описание
Реализация слайдера на чистом JavaScript по макету из Figma.

## Функционал
- Переключение слайдов стрелками (по кругу)
- Переключение слайдов через точки
- Переключение слайдов через вкладки сверху
- Динамическое обновление текста и изображения

## Технологии
- HTML
- CSS
- JavaScript (DOM)
