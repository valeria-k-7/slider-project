# Slider Project

Учебный проект по курсу SkillFactory (Модуль 42. «Слайдер на JS»).

## Описание
Слайдер, реализованный по макету из Figma.  
При переключении слайдов меняются изображение и информация об объекте.

## Функционал
- Переключение слайдов стрелками (по кругу)
- Переключение через точки
- Переключение через вкладки
- Обновление текста и изображения при смене слайда

## Технологии
- HTML
- CSS
- JavaScript
